# 核心期待与主线

适用范围：选题、一句话扩写、核心设定、大纲立项。核心期待还没写清时，不进入分集和正文。

本文件自洽。信息差的做法见 `references/methodology-information-gap.md`，阶段事件见 `references/methodology-emotion.md`。

## 定义

- **核心梗**：一句话能懂，并且能自然长出主要冲突的设定或关系机制。
- **核心卖点**：作品向观众承诺的主要情绪体验，由核心梗、人物关系和冲突方式一起提供。
- **主线目标**：主角试图做成的具体事情。
- **核心矛盾**：挡住这个目标的主要对立关系或条件。
- **核心期待**：观众已经知道、已经在意、并且持续等着兑现的具体结果。核心期待可以不等于主角目标。
- **剧情期待**：观众明确知道未来有一件重要的事会发生，并想看它怎么发生、怎么被应对。

## 优先级

1. 观众的核心情绪需求、核心卖点、观看期待。
2. 人物动机、人物关系、事件因果。
3. 冲突递进、局面变化、情绪兑现。
4. 集数、场景数、卡点位置等形式安排。

快节奏和人物逻辑冲突时，先改剧情构造，不用人物降智硬撑。事件变多和核心期待被冲淡冲突时，留下能推动期待的事件。固定集数、固定比例、固定卡点集，只有项目写明了才执行。

## 开写前锁定的条件

目标平台、男频或女频及细分受众、题材、故事模式、总集数、单集时长、商业模式、已确定设定、对标作品、交付格式、禁止修改项。

- 没给的条件标成待定。只有不影响往下写时才采用临时假设，并写明假设是什么。
- 没写商业模式，就不套付费卡点。
- 没写某一集是一卡，就不把某一集当成通用付费集。
- 不编造对标剧的热度、播放量、转化率、平台规则，也不把某种写法说成已经被证明能带来收入或留存。

## 选题顺序

1. **受众要什么情绪**：逆袭、复仇、打脸、被坚定选择、追悔、身份反转、反抗压迫、家庭关系重组等。按题材取舍，不把这份名单当配额。
2. **谁和谁处于什么关系**：身份、权力、利益、情感。
3. **矛盾条件**：欲望不一致、信息不对等、这段关系退不出去。
4. **一句话核心梗**：身份或关系反差，加上触发事件，加上因此持续存在的冲突。
5. **具体期待**：观众最想看见的场面或关系结果。
6. **差异化**：改关系里的权力、事件切口、触发方式、行动策略或兑现方式。不靠堆设定。

核心梗合格，需要同时满足：

- 去掉人名还能一句话说清。
- 马上能推出一场有冲突的戏。
- 主角有目标，反方或环境有阻力。
- 至少能推出三轮局面不同的冲突，不够只做一个噱头。
- 情绪价值能持续，不依赖大段背景说明。

## 从关键场景反推

可以先确定一个高情绪场面或投流素材，再反推全剧：

1. 场面里谁在争、争的是什么、观众这时该有什么情绪。
2. 这一场兑现了什么，或者吊起了什么。
3. 反推人物关系、前置事件和看懂这场所需的最少背景。
4. 推出后面还能继续使用的冲突机制。
5. 确认全剧不是为了一个噱头去拼无关事件。

不照搬其他作品的独创台词、人物配置和具体情节。

## 主角目标和观众期待分开

- **主角目标**：角色以为自己要做什么。
- **观众期待**：观众真正想看什么发生。

两者可以相反。例如角色想结束契约婚姻，观众想看双方真正相爱。这个错位可以驱动关系戏。不能用“他们后来会怎样”代替具体期待。

持续期待优先落在一个观众已经听懂、觉得重要、并且能预见发生条件的未来节点上。

公式：**明确的未来事件 + 角色当前目标或风险 + 还没兑现的结果。**

示例：三日后的宫宴上，有人准备公开陷害皇帝；主角必须在宴前找到破局办法。观众知道宫宴是冲突节点，等的是主角怎么活下来、怎么反击，不是空等“后面也许有事”。

检查：

- 观众能不能说出下一件重要的事是什么。
- 观众能不能说出这件事为什么关系主角的命运。
- 观众能不能想象期待兑现时的情绪回报。
- 事件越近，人物的行动和风险是否一起变化。

可以留悬念。不能靠一直瞒着全部重要信息来代替观看期待。

## 主线句

主角身份 + 核心欲望 + 最大阻碍 + 主要行动手段。

主线是持续推动选择和对抗的方向，不是剧情流水账。阶段目标可以变，终极目标不能无故更换。每个重要事件至少完成一件事：推进主线、加深主要关系、加重核心障碍、改变信息差、兑现核心情绪。

## 关系与对抗

每对核心关系写清：双方各要什么，为什么必须接触，谁掌握权力或资源，各自知道什么，为什么不能直接谈妥或分开，哪类事件能改变彼此的位置。

关系是冲突发生器，不是身份标签。关系变化要落在选择、行为、代价、信任、依赖、权力或认知上。

- 主角靠主动选择改变局面。弱势开局不等于全程被动。
- 反方要有利益，以及实施阻碍所需的资源、能力或关系。单纯坏，构不成有效冲突。
- 反方可以类型化、夸张化，但不能没有因果地反复加害。
- 能力边界、已知信息、既定目标、情绪状态前后一致。

不是每部剧都要三层反派、隐藏身份或爱情线。卖点不需要的对抗，就不加。

## 选题交付

写清：题材、目标受众、情绪需求、一句话核心梗、核心卖点、主角目标、核心障碍、核心期待、人物关系优势、差异化、首个高情绪场景。

未确定项单独列出。
