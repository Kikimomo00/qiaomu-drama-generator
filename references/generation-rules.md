# 短剧生成规则

本文件是强戏剧短剧的可选骨架。核心期待、信息差、情绪递进和卡点的判断，以任务路由指定的方法论文件为准。

- 用户指定了集数、节奏、不要系统、不要复仇或不要爱情时，以用户指定为准。
- 品牌、正向题材、关系短剧和现实题材，不为了套公式硬加系统、隐藏身份或三层反派。
- 用户没指定付费卡点时，不把某一集写成默认付费集。
- 公式和下面的分集段落用来加速表达。它们与人物因果、核心期待冲突时，保留因果和期待。

## 高概念公式

```text
一个【弱势但有隐藏优势的人】，在【极端压迫场景】中，为了【守护对象/核心欲望】，借助【金手指/身份/能力/信息差】，与【强关系反派】持续对抗，最终完成【身份/财富/爱情/权力/亲情】的逆转。
```

一句话故事：

```text
当【主角】在【关键场景】被【反派】逼到绝境时，他/她意外获得/暴露【核心能力】，从【第一件小事】开始反击，最终在【更大危机】中完成【终极逆转】。
```

标题公式：

- 身份反差 + 关键事件 + 结果反转。
- 弱势处境 + 金手指 + 逆袭目标。
- 关系冲突 + 情绪承诺 + 钩子身份。

## 人物关系

强戏剧短剧的主角默认有表面弱势身份、隐藏优势、外部目标、内在需求和前 3 集内的主动选择。品牌、正向题材或用户明确不要弱势开局时，改成与核心期待匹配的处境，不硬套弱势身份。

反派使用三层阶梯：

```yaml
early_antagonist:
  role: 亲戚、婆婆、小三、同事、同村恶人、酒楼伙计、假千金
  function: 制造前 3 集压迫
middle_antagonist:
  role: 商业竞争者、家族二房、前夫、老板、地方恶霸、同行
  function: 阻止主角扩大成果
final_antagonist:
  role: 幕后黑手、豪门掌权人、县令/权贵、资本方、真正凶手
  function: 制造最终危机并完成大反转
```

优先使用高压绑定关系：前夫/前妻、婆媳、真假千金、赘婿/岳家、霸总/契约妻、救命恩人/错认者、闺蜜/背叛者、老板/被抢功员工、母亲/不孝儿女、商户/掌柜、村民/恶霸、Alpha/命定伴侣、黑帮继承人/债务新娘。

## 金手指与限制

金手指必须好懂、可视化、可持续升级，但不能无限制解决一切。

常用类型：

- 系统面板：商城、返现、任务、属性、空间、签到。
- 重生记忆：前世记忆、未来行业趋势、反派阴谋。
- 隐藏身份：豪门继承人、战神、神医、律师、黑客、董事长。
- 专业能力：医术、厨艺、商业、法律、鉴宝、设计、表演。
- 证据链：录音、监控、合同、病历、亲子鉴定、账本。
- 社会资源：哥哥团、贵人、旧部、老师、客户、粉丝。
- 奇幻标记：狼人印记、王室血统、灵泉、空间、异能。

每个金手指至少有一个限制：每日限购、余额不足、不能当众暴露、使用会被怀疑、需要完成任务、只能兑换低级物资、证据不完整、身份暂时不能公开、能力只能解决局部问题、贵人不能随时出现。

有金手指的强戏剧短剧，默认在前 3 集内第一次使用它，并解决一个最小危机。没有金手指的题材不要硬加。用户指定了更晚揭示时，以用户设定为准。

## 单集情绪模型

```text
开头承接钩子或直接冲突
→ 反派施压 / 危机升级
→ 主角被迫选择
→ 主角小反击或得到新资源
→ 结尾卡在更大机会/危险/真相前
```

压缩为：压、逼、变、钩。这是单集速记。阶段递进、爽点五个环节，以及“重复机制、不重复手段”，以 [情绪递进与阶段事件](methodology-emotion.md) 为准。两者冲突时，保留人物因果和有效递进。

常用爽点：打脸、复仇、护短、偏爱、暴富、身份、追悔、真相、成长。

## 前 3 集强开局

第 1 集：极端压迫。主角落入绝境，亲人/尊严/生存受威胁，反派做出可恨动作，主角苏醒或做出第一个反应，结尾出现更大压迫或反击信号。

第 2 集：压迫升级 + 主角觉醒。反派进一步伤害主角要守护的人，主角意识到不能再忍，金手指激活、证据出现或隐藏身份露一角，结尾卡在能力即将验证。

第 3 集：第一次验证。主角第一次使用能力/资源，解决最小危机，让一个人震惊或开始相信主角，提出更大目标，结尾出现新机会或新麻烦。

第 1 集无论题材，都要完成“停下来、看懂、起情绪、承诺后续”四项任务，见 [第一集与前三集](methodology-opening.md)。上面的绝境、觉醒、第一次验证是强戏剧短剧的默认分法。单集很短、用户指定了别的开局，或题材不是逆袭时，可以调整第 2 集和第 3 集的分工，但不能只交代背景。

## 指定体量时的可选骨架

用户指定 20、60 或 100 集，或接受默认 20 集时，可以把下面的段落当规划草稿。题材对不上的节点删掉或改写，不为了填满节点加无关支线。用户指定其他集数时，按集数重新分配阶段，不按比例硬套这些段落。用户没指定卡点集数时，这些段落里的位置都不是付费集。

20 集：

```text
1-3 集：强开局，绝境、觉醒、第一次验证。
4-7 集：确定方向，寻找资源，首次交易/交锋，第一桶金或第一段证据。
8-10 集：成果回到原关系场，引发信任或嫉妒，贵人线或高层关系展开。
11-14 集：秘密布局，反派察觉，产品/证据成型，公开交锋或关键证人出现。
15-17 集：扩大规模，进入更高圈层，阶段性爽点释放。
18-20 集：成果刺激外部眼红，主角提出升级计划，开启新阶段并埋更大危机。
```

60 集：

```text
1-5 集：强开局，主角从绝境活下来。
6-15 集：第一桶金 / 第一证据 / 第一段关系成型。
16-25 集：成果扩大，反派从嘲讽变成阻挠。
26-35 集：产业、身份或爱情进入高压圈层。
36-45 集：强反派登场，主角低谷，核心秘密被威胁。
46-55 集：主角反布局，盟友、资源、证据回归。
56-60 集：终极反击，情绪收束，关系和目标完成。
```

100 集：

```text
1-10 集：强开局，完成最小翻身。
11-25 集：第一主线成型，第一批反派被打脸。
26-40 集：进入更大市场/豪门/权力圈，出现中期强反派。
41-55 集：主角被围剿，感情或亲情误会加深。
56-70 集：低谷与反转，主角隐藏底牌逐步露出。
71-85 集：反布局，证据、盟友、资源全面回归。
86-100 集：终极反杀，身份/财富/爱情/权力/亲情收束。
```
