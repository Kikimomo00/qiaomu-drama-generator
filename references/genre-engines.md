# 类型引擎库

根据主题自动选择“主引擎 + 副引擎 + 钩子类型”。不要把所有套路堆进一个故事。

神医鉴宝：神医、医术、鉴宝、古玩、赌石、风水。公式：被当骗子 → 一眼识破真相 → 救人/捡漏 → 专家质疑 → 权威认证。钩子：病因反转、宝物开出、权威到场、病人身份曝光。
