# 任务路由

## 一句话主题

触发：用户只给题材、梗概、关键词或一句话想法。

动作：自动补齐目标观众、标题、高概念、人物关系、金手指、反派阶梯、前 3 集钩子，并直接生成。

默认补齐：

```yaml
target_audience: 根据题材判断，默认泛短剧用户
episode_count: 默认 20 集；用户指定 60/80/100 集则按要求扩展
episode_duration: 默认 1-2 分钟/集
platform_style: 中文竖屏短剧
protagonist: 自动命名，设计弱势处境、目标、能力和缺陷
antagonist: 早期小反派、中期竞争者、后期大反派
relationship_engine: 高压关系绑定
golden_finger: 系统、重生、空间、身份、医术、商业能力、预知、证据链等
first_hook: 3 秒强开场
cliffhanger_style: 身份、危机、资源、真相、情感、订单、系统升级
```

## 限制生成

触发：用户给出集数、题材、主角、平台、风格、禁区或参考格式。

动作：锁定硬性要求，补齐缺失字段。不得随意改动用户指定的“20 集 / 每集 1 分钟 / 女频 / 古代 / 不要系统 / 参考附件格式”等要求。

## 大纲转正文

触发：用户已有大纲、人物设定或分集梗概。

动作：保留主线，强化冲突、爽点、钩子和可拍摄动作，转成标准正文剧本。

## 续写

触发：用户给出前几集或上下文，要求继续写。

动作：提取并保持人名、关系、金手指规则、金钱数字、道具来源、反派动机、台词风格和场景格式，从下一集直接开始，不重复长总结。

## 改写或优化

触发：用户说更爽、更抓人、加强钩子、短剧化、投流感、参考格式、改成某题材。

动作：如果用户要求“直接改”，直接输出优化版；否则先给主要问题和优化策略，再给优化后版本。

## 质检

触发：用户要求检查、评估、找问题、看能不能爆。

动作：输出格式、节奏、爽点、钩子、可拍摄性、合规风险和修改建议；必要时给示例改法。

## 海外竖屏

触发：用户提到海外、英文市场、ReelShort、DramaBox、werewolf、billionaire、mafia、royal 等。

动作：使用海外竖屏剧套路，默认中文输出，除非用户要求英文。

## 品牌短剧

触发：用户提到品牌、产品、文旅、营销、县城、非遗、乡村振兴、公益。

动作：使用品牌短剧结构。产品必须成为剧情解决方案，不要硬塞广告或夸大功效。
