# 分集、场景与人物

适用范围：大纲已经确定之后，写单集细纲、场景和正文；续写下一集；改某一场戏。核心期待还没定时，先读 `references/methodology-expectation.md`，不要用本文件直接堆正文。

行级标记、场景编号和文件交付以 `references/script-format-spec.md`、`references/output-format.md` 为准。本文件不新增标记，也不要求把下面的字段写进正文标题。

## 人物要写清的驱动

每个人物至少能回答：身份，外在处境，显性目标，深层欲望，当前障碍，可以使用的资源和能力，底线或代价，与核心人物的利益和情感关系，主要行动策略，发生转变的条件。

“高冷、腹黑、强大、善良”这类标签不能代替上面的驱动。

常见侧重，只在题材吻合时使用：

- 偏男频的身份差、能力差、权力反转，通常要从很大的背景里只切最有戏的一件事。背景可以复杂，正文不必复述整段经历。
- 偏女频的关系对抗，要写清双方目标、为什么绑在一起、为什么不能轻易离开、什么行动会改变彼此的认知。爱情是关系题材的一个选项。复仇、成长、家庭按各自的核心卖点决定主线，不默认都写成爱情。

避免工具人：

- 反方的每一步都有能看懂的利益目标。
- 主角可以被动开局，随后要做出主动选择。
- 对抗升级到利益、选择和后果，不只比较谁骂得更狠。
- 台词按身份、认知和关系区分，避免所有人说同一种短句狠话。

这些不是题材配额。对不上的项目不要硬套。

## 每一集的六项

1. **本集目标**：这一集想改变什么。
2. **主要冲突**：双方为什么不能同时如愿。
3. **核心行动**：谁做了什么。
4. **事件结果**：哪种局面变了。
5. **情绪与期待**：积累、兑现、逆转或升级了什么。
6. **小卡点**：下一集即将出现的具体结果是什么，观众为什么关心。

“本集吵一架”“主角很伤心”“反派更嚣张”不是有效的分集。小卡点的有效标准见 `references/methodology-cards.md`。

对外输出分集大纲时，保留原有的“剧情 / 爽点 / 钩子”。剧情覆盖目标、行动和结果。爽点覆盖情绪兑现。钩子覆盖小卡点。信息差发生变化时，在剧情或钩子里写明是谁的认知变了。

## 一场戏的五段

- **入场**：人物带着什么目标进入场景。
- **碰撞**：具体阻力是什么。
- **交锋**：双方怎样用行动、筹码、证据或选择改变局面。
- **转折**：出现了什么新的信息、关系或代价。
- **出场**：离开时，故事状态和进入时有什么不同。

一场戏可以不五段齐。如果状态完全没有变化，就检查这场还有没有必要。纯解释、纯争吵，如果没有造成新的局面，就不算一个有效事件。

## 正文怎么写才拍得出来

- 台词直接说当下的目标和冲突，避免大段讲解设定。
- 选择、表情和行动与情绪一致，并且能被画面或表演做出来。
- 不用旁白代替关键的戏剧行动。
- 语言符合身份。不为了显得强势或暧昧，让角色突然越界，或说出不符合身份的话。
- 控制不必要的场景、演员和专业信息。复杂设定改成看得懂的实际冲突。
- 相邻场景保住时间、空间、道具、信息和行动的连续。

## 写作顺序

先确认大纲，再写正文。用户只要想法，就不写完整剧本。用户只要分析，就不改写。正文不能无故更换已经确定的主线、人物动机、关系和关键节点。

续写从下一集直接开始。先核对人名、关系、能力规则、数字、道具来源、反派动机和场景编号，再写新的事件。

## 单独要卡片时的字段

用户明确要求立项卡、阶段卡或单集卡时，使用下面的字段。用户只说“写一个短剧”时，默认交付仍然是《剧名》、一、剧本、二、正文剧本，不先输出一整套卡片。

立项卡：

```text
作品名：
目标平台／受众／商业模式：
题材与核心元素：
一句话核心梗：
主要情绪需求：
核心卖点：
主角目标／核心障碍／行动手段：
核心人物关系及利益冲突：
核心期待：
核心信息差：
首集高情绪场景：
前三集阶段性兑现：
第一阶段大事件：
中段递进方式：
最终兑现：
与可迁移机制的差异：
未确定条件：
```

项目没有一卡、二卡、三卡时，不把这三行改写成虚构的付费集。第一阶段、中段、终局三行已经够用。项目指定了卡点集数，才在对应行写上集数。

阶段卡：

```text
阶段：
阶段开始时的主线状态：
阶段核心期待：
主要人物的目标与阻力：
阶段大事件：
事件链及因果：
本阶段信息差：
主要情绪及阶段爽点：
与上一阶段的实质变化：
阶段末的大卡点或阶段大事件：
兑现了什么旧期待：
建立了什么新期待：
```

单集卡：

```text
第 X 集：
本集目标：
核心人物及当下动机：
冲突起点：
人物行动与事件因果：
信息差变化：
情绪积累／兑现：
本集结束时的状态变化：
小卡点：
与下一集的因果衔接：
```
