# 《荒年穿越短剧制作（完整）.docx》格式抽取记录

来源：用户提供的《荒年穿越短剧制作（完整）.docx》参考文档。

用途：优化 `qiaomu-drama-generator` 的正文剧本格式约束。该文档是格式与写法参考，不是题材、人物、系统设定或剧情模板。

## 抽取结果

- 顶层顺序：文档标题 → `一、剧本` → 项目简介 → `二、正文剧本` → 剧名 → 正文。
- 分集标记：`第 1 集`、`第 2 集`。
- 场景标记：`1-1 村子茅草屋 日内`、`9-2 一座红木门大宅 日内【字幕：燕子巷柳府】`。
- 人物标记：`人物：徐小梅，张秀娥，徐长寿`。
- 动作标记：普通动作行、`△`、`Δ` 都存在。
- 对白标记：`人物名：对白`、`人物名（状态）：对白`。
- 内心与旁白：`人物名（OS）：...`、`人物名（VO）：...`、`系统（VO）：...`。
- 系统面板：`兑换商城系统面板（字幕）：【...】`、`兑换商城系统面板（字幕 + VO）：【...】`。
- 补充视觉标记：`【字幕：...】`、`【闪入】...【闪入结束】`。
